# Лендинг — Шехерезада Куралбек (юрист)

Одностраничный статический сайт. Исходник перенесён из `D:\Shakh-site` и дополнен
3D-секцией «Принципы» с фигурой Фемиды.

## Структура

```
index.html                 — вся страница (разметка + стили + скрипты)
images/                    — фотографии
assets/js/themis.js        — 3D-сцена Фемиды (Three.js)
assets/models/themis.glb   — 3D-модель Фемиды (3.9 МБ, meshopt-сжатие)
assets/vendor/             — локальные библиотеки (Three.js r169, GLTFLoader,
                             meshopt-декодер) — без CDN, работает офлайн
```

## Запуск

Нужен любой статический сервер (ES-модули не работают с file://):

```powershell
python -m http.server 5599 --directory "<путь к этой папке>"
```

Затем открыть http://localhost:5599. В проекте Law calendar сервер уже прописан
в `.claude/launch.json` под именем `shakh-landing`.

## Деплой на Railway

В папке есть `Dockerfile` (Caddy отдаёт статику, слушает `$PORT`).

Через дашборд: New → GitHub Repo → этот репозиторий, в Settings сервиса
указать **Root Directory = `landing-shakherezada`**, после деплоя
Settings → Networking → **Generate Domain**.

Через CLI: из этой папки `railway login` → `railway init` → `railway up`
→ `railway domain`.

## 3D-Фемида

- Фемида — постоянный фон всей страницы: канвас `#themis-canvas`
  зафиксирован на весь экран позади контента.
- Первый экран — только статуя в полный рост, без текста; при прокрутке
  текст hero въезжает анимацией (см. `heroFade` в index.html).
- Камера летит по «якорным ракурсам» секций (массив `ANCHORS` в
  `assets/js/themis.js`): полный рост → наезд к лицу («Обо мне») →
  весы («Услуги») → профиль → сторона с мечом («Преимущества») →
  отъезд в полный рост (CTA) → финал лицом к зрителю (контакты).
  Прокрутка плавно интерполирует камеру и подкручивает статую.
- Настройка ракурсов из консоли: `__setCam({dist,camY,lookY,x,spin})`,
  вернуть обычное поведение — `__setCam(null)`.
- Интро-свет: прожектор с видимым конусом (`buildLightCone`) освещает
  статую на первом экране и гаснет по мере прокрутки.
- Все секции после интро лежат в одном общем полупрозрачном блоке
  `.shell` — отдельных фонов у секций нет.
- Фото юриста: `images/portrait.jpg`, блок `.about-photo` в «Обо мне»
  с анимацией появления (сдвиг + наезд + световая полоса + парение).
- Палитра: материал модели заменён в рантайме на сине-голубой металл под
  стилистику лендинга (см. `fitModel()` в `assets/js/themis.js`).
- Модель: «Lady Justice (Themis)» из бесплатной 3D-галереи Tripo AI
  (studio.tripo3d.ai, модель отдаётся галереей для свободного скачивания;
  сгенерирована ИИ). Файл лежит локально — сайт от Tripo не зависит.
- Замена модели: положите любой `.glb` в `assets/models/themis.glb` —
  он будет автоматически отмасштабирован, поставлен на пьедестал и
  перекрашен. Если файла нет, рисуется запасная процедурная статуя.
- Производительность: модель грузится лениво (когда секция близко),
  рендер останавливается вне экрана и на скрытой вкладке,
  уважается `prefers-reduced-motion`.
