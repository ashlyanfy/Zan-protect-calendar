# ZanProtect Календарь

Командный календарь судебных заседаний и юридических событий. PWA (устанавливается на телефон), React + TypeScript + FastAPI + PostgreSQL.

**Прод:** https://app-production-b1ee.up.railway.app (Railway, проект `zanprotect-calendar`)

## Аккаунты и роли

- Вход по логину и паролю (JWT, пароли хранятся как PBKDF2-хэши).
- **Админ** (Шехерезада): создаёт и удаляет аккаунты сотрудников (кнопка 👥 в шапке), может редактировать любые события.
- **Сотрудник**: свои события + общие события команды.
- События бывают **личные** (видит только автор) и **общие** (видят все, редактирует автор или админ).
- Логины и пароли команды — в `backend/seed_users.json` (файл в .gitignore, в репозиторий не попадает). На проде аккаунты созданы через переменную окружения `SEED_USERS`; при первом запуске создаются только отсутствующие логины.

## Локальный запуск

**Бэкенд** (порт 8000, локально использует SQLite `backend/zanprotect.db`):

```bash
cd backend
.venv/Scripts/uvicorn app.main:app --reload --port 8000
```

**Фронтенд** (порт 5173, проксирует `/api` на бэкенд):

```bash
cd frontend
npm run dev
```

Открыть: http://localhost:5173

## Деплой на Railway

1. Запушить репозиторий на GitHub и создать проект в Railway из этого репо — `Dockerfile` и `railway.json` подхватятся автоматически.
2. Добавить в проект плагин **PostgreSQL** — Railway сам передаст `DATABASE_URL` сервису (если нет, добавить переменную `DATABASE_URL = ${{Postgres.DATABASE_URL}}`).
3. Открыть выданный домен — фронтенд и API работают с одного сервиса.

Переменные окружения:

| Переменная | Описание |
| --- | --- |
| `DATABASE_URL` | PostgreSQL URL (задана ссылкой `${{Postgres.DATABASE_URL}}`). Без неё — SQLite для локальной разработки |
| `SECRET_KEY` | Подпись JWT-токенов (на проде задана случайная строка) |
| `SEED_USERS` | JSON-массив аккаунтов для первичного создания (см. формат `backend/seed_users.json`) |
| `ADMIN_LOGIN` / `ADMIN_PASSWORD` / `ADMIN_NAME` | Запасной админ, создаётся только если ни одного админа нет |
| `CORS_ORIGINS` | Список разрешённых origin через запятую (нужно только если фронт хостится отдельно) |

## Структура

- `backend/` — FastAPI, SQLAlchemy 2.0, Pydantic v2. CRUD `/api/events`, healthcheck `/api/health`
- `frontend/` — Vite + React + TS, PWA (vite-plugin-pwa), режимы День/Неделя/Месяц, напоминания через браузерные уведомления
- `Dockerfile` — multi-stage сборка: фронтенд собирается и раздаётся FastAPI со того же домена
