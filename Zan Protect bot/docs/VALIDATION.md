# Проверка реализации

## Актуальный результат версии 0.2 — 11.10.2026

Результаты ниже заменяют ограничения ранних прогонов, сохранённых далее для истории.

- Полный pytest с реальным PostgreSQL 17: **69 passed, 34.76 s**. Ruff: без ошибок. `pip check`: зависимости согласованы.
- Проверены шифрование и удаление сессий, очередь и квоты, восстановление заданий, публикация и срок действия знаний, семантический поиск, подтверждение фактов и генерация документов.
- Собран Linux Docker-образ `zan-protect:release`. Миграции применены к отдельной тестовой PostgreSQL; повторное применение проверено.
- В контейнере FastAPI: `/health` и `/ready` — 200, запрос без авторизации — 401, авторизованный экспорт PDF на казахском — успешно.
- Tesseract содержит rus/kaz/eng; извлечение текста из синтетического сканированного PDF через отдельный процесс прошло успешно.
- Синтетические PDF на RU/KK отрисованы Poppler и визуально проверены. DOCX на RU/KK отрисованы штатным `render_docx.py` в Linux с LibreOffice; обе страницы проверены визуально, обрезания и пропавших казахских символов нет. Это проверка оформления, не юридическая экспертиза шаблонов.
- Версии runtime закреплены в `requirements-runtime.txt`; полное проверенное окружение — `requirements-tested.txt`.

**Не проверено:** реальная доставка через Telegram, платные LLM/embedding/web-search вызовы, качество ответов выбранной модели, юридическая корректность корпуса и шаблонов, развёртывание в аккаунте Railway. Нет предоставленных ключей и экспертно проверенного корпуса. Тесты контроллера используют подмену Telegram и LLM.

разрешённые домены без подмены суффикса, фиксированные поисковые темы, отсутствие web-вызова без согласия,

Первый прогон выявил отсутствие timezone data в Windows-окружении; добавлена обязательная зависимость `tzdata`.
После установки итоговый прогон полностью прошёл. Зафиксированные версии окружения — `requirements-tested.txt`.
Это снимок проверенного окружения, не lockfile с хешами и не гарантия безопасности всех зависимостей.
